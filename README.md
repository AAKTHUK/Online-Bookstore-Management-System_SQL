INTRODUCTION

I built an Online Bookstore SQL project to simulate a real-world e-commerce database. The goal was to design a relational database, manage book inventory, track customers, and analyze sales data using SQL queries.
The project focuses on database design, data import, joins, aggregations, and analytical queries.

DATABASE STRUCTURE


Books Table

Stores book details like title, author, genre, price, and stock.


Customers Table

Contains customer information such as name, email, phone, and country.


Orders Table

Stores transaction data like order date, quantity, and total amount.


TECHNICAL SKILLS

In this project I implemented multiple SQL concepts including:

Table creation using DDL commands

Importing CSV data using COPY command

Joins between tables

Aggregate functions like SUM, AVG, COUNT

Filtering using WHERE

Grouping using GROUP BY

Sorting using ORDER BY

Subqueries


BUSINESS INSIGHTS

Using SQL analysis we can answer business questions such as:

Which genre sells the most

Which customers generate the highest revenue

Which books are running low on stock


CONCLUSION

This project helped me strengthen my understanding of relational database design and SQL analysis, and it simulates real-world sales data analysis used in e-commerce platforms.
